# Official tool documentation and tutorials

Renderer documentation does not define scientific validity or journal compliance. Use the simplest installed tool that preserves evidence, editability, and the requested output.

- diagrams.net/draw.io, [official documentation](https://www.drawio.com/doc/). Editable diagram creation and export.
- Inkscape, [official learning resources](https://inkscape.org/learn/). SVG/vector editing and export.
- Matplotlib, [official documentation](https://matplotlib.org/stable/). Reproducible Python plotting.
- ggplot2, [official site](https://ggplot2.tidyverse.org/). Grammar-of-graphics plotting in R.
- PGF/TikZ, [CTAN package page](https://ctan.org/pkg/pgf). TeX-native programmable vector graphics.
- PlotNeuralNet, [official GitHub repository](https://github.com/HarisIqbal88/PlotNeuralNet). Python/TikZ neural-network architecture figures.
- D3.js, [official documentation](https://d3js.org/). Browser-based data-bound SVG/Canvas rendering.

## Routing cautions

- draw.io is strong for ordinary frameworks and collaboration, but does not make data plots reproducible.
- PlotNeuralNet is useful for layer architecture, not automatically for a whole method pipeline.
- TikZ aligns well with LaTeX but may be harder for collaborators to edit.
- D3 offers detailed SVG control but adds browser tooling; do not choose it for a routine static plot without a concrete benefit.
- Inkscape is useful for vector refinement; preserve the reproducible upstream plot source.
